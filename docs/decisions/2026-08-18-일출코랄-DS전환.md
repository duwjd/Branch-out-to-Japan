# 결정 — 일출 코랄을 앱 전역 디자인 시스템으로 (2026-08-18)

## 결정
`LP_Components` 시트를 **디자인 시스템 정본**으로 승격한다. UI 브랜드색을 스티비 coral `#ff6464`에서 **로고의 일출 코랄 `#FF6F61`** 로 바꾸고, 중립 팔레트도 **웜 크림 표면 + 쿨 네이비 잉크**로 교체한다. 적용 범위는 랜딩과 `/app` 전 화면, 그리고 생성 산출물(상세페이지 템플릿·리포트 슬라이드)까지다.

- 정본 자산: [design/references/LP_Components.svg](../../design/references/LP_Components.svg)
- 실측 스펙: [design/lp-components-spec.md](../../design/lp-components-spec.md)
- 토큰 구현: [app/globals.css](../../app/globals.css)

## 경위
PR #37("feat: Figma 시안 반영 + 서비스 플로우 개편")이 같은 팔레트를 **랜딩 한정** `--color-lp-*`로 먼저 넣었다. 당시 주석은 *"앱 UI 브랜드색은 그대로 coral #ff6464다. lp-coral은 랜딩 한정 표면색으로, 로고 색을 UI 토큰으로 승격한 것이 아니다"* 였다.

그 상태로 두면 **한 서비스 안에 브랜드 코랄이 둘**(`#ff6f61` 랜딩 / `#ff6464` 앱)이 되고, 랜딩에서 앱으로 넘어가는 순간 크림 배경이 쿨 그레이로 바뀐다. 그래서 전역으로 통일했다.

## 폐기되는 규칙
- `CLAUDE.md` · `design/design-system.md`의 **"로고 색을 UI 토큰으로 승격하지 않는다"** 조항 폐기. 로고 잉크 `#182333` = `--color-ink`, 일출 코랄 `#FF6F61` = `--color-coral`.
- `design/design-system.md`의 **"인풋 포커스는 브랜드색이 아닌 회색(#70737c)"** 조항 폐기. 시트가 전 컴포넌트 포커스를 **코랄 3px 링**으로 통일한다.

> 예외: **일출 그라디언트**(`#FF6F61`→`#FF9B70`)는 여전히 **로고 심볼 전용**이다. UI 면에는 단색만 쓴다.

## 면과 글자를 나눈 이유 (시트에서 의도적으로 이탈)
시트 원색을 소형 텍스트에 그대로 쓰면 AA(4.5:1) 미달이다:

| 조합 | 시트 원색 | 대체 토큰 | 대비 |
|---|---|---|---|
| 코랄 텍스트 on 크림 | 2.57 ✕ | `--color-coral-strong #C93F2E` | 4.68 ✓ |
| 앰버 배지 텍스트 | 2.15 ✕ | `--color-amber-text #8F6412` | 4.78 ✓ |
| danger 배지 텍스트 | 3.71 △ | `--color-danger-text #C13A3A` | 4.69 ✓ |
| success 배지 텍스트 | 3.67 △ | `--color-green-text #26775B` | 4.81 ✓ |

**면**(버튼 배경·도트·보더·아이콘)은 시트 원색 그대로, **글자**만 파생색을 쓴다. 코드베이스가 이미 `text-coral`(large/bold 강조, 125곳) / `text-coral-strong`(소형 텍스트, 120곳)로 나눠 쓰고 있어서, 값만 바꿔도 120곳이 자동으로 AA를 만족하게 됐다.

## 미해결 — Primary 버튼 라벨
`#FF6F61` 위 흰 글자는 **2.73:1로 AA 미달**이다(라벨 15px bold라 large text 예외도 못 받는다). 시트가 그렇게 그려져 있어 그대로 뒀다. 해소하려면 셋 중 하나가 필요하다:
1. Primary 면을 `#D14B3B` 수준으로 낮춘다 (대비 4.5, 시트와 눈에 띄게 다름)
2. 라벨을 키우고 면도 함께 조정한다
3. 브랜드 결정으로 수용하고 문서에 남긴다
