# 결정 — 디자인 시스템을 일출 코랄로 전환 (2026-08-18)

## 결정
`LP_Components` 시트를 **디자인 시스템 정본**으로 승격한다. UI 브랜드색을 스티비 coral `#ff6464`에서 **로고의 일출 코랄 `#FF6F61`** 로 교체하고, 중립 팔레트도 **웜 크림 표면 + 쿨 네이비 잉크**로 전면 교체한다.

- 정본 자산: [design/references/LP_Components.svg](../../design/references/LP_Components.svg)
- 스펙 추출: [design/lp-components-spec.md](../../design/lp-components-spec.md)
- 토큰 구현: [app/globals.css](../../app/globals.css)

## 폐기되는 규칙
직전까지 `CLAUDE.md` · `design/design-system.md` · `design/DESIGN.md`는 **"로고 색은 로고 전용 고정색이며 UI 토큰으로 승격하지 않는다"** 고 못박고 있었다. 이 결정으로 **해당 조항을 폐기**한다. 로고 잉크 `#182333`과 일출 코랄 `#FF6F61`은 이제 UI 토큰이다(`--color-ink`, `--color-coral`).

> 다만 **일출 그라디언트**(`#FF6F61`→`#FF9B70`)는 여전히 **로고 심볼 전용**이다. UI 면에는 단색 `#FF6F61`만 쓴다.

## 왜
- 브랜드가 YOAKE로 리브랜딩된 뒤(2026-08-18) 로고와 UI의 코랄이 미묘하게 어긋나 있었다(`#FF6F61` vs `#ff6464`). 한 화면에 둘이 같이 놓이면 색 오류처럼 보인다.
- 스티비 coral은 리브랜딩 이전의 시드 레퍼런스 잔재였고, 이제 브랜드 근거가 없다.
- 웜 크림 캔버스는 일출 컨셉과 결이 맞고, 기존 `#f7f7f8`(쿨 그레이)보다 코랄과 충돌이 적다.

## 접근성 — 시트에서 벗어난 부분 (의도된 이탈)
시트 원색을 소형 텍스트에 그대로 쓰면 WCAG AA(4.5:1)에 미달한다. 실측:

| 조합 | 대비 | 판정 |
|---|---|---|
| `#FF6F61` 텍스트 on 크림 | 2.57 | ✕ |
| `#E39A22` 배지 텍스트 on `#FDF3E4` | 2.15 | ✕ |
| `#D94848` 배지 텍스트 on `#FBEDED` | 3.71 | △ large만 |
| `#2D8C6B` 배지 텍스트 on `#E8F4F0` | 3.67 | △ large만 |

→ **면(버튼·도트·보더·아이콘)은 시트 원색을 그대로 쓰되, 글자는 파생 `*-text` 토큰을 쓴다.**

| 토큰 | 값 | 대비(크림) |
|---|---|---|
| `--color-coral-text` | `#C93F2E` | 4.68 |
| `--color-amber-text` | `#8F6412` | 4.95 |
| `--color-danger-text` | `#C13A3A` | 5.04 |
| `--color-green-text` | `#26775B` | 5.12 |

## 미해결 — Primary 버튼 라벨
`#FF6F61` 위 흰 글자는 **2.73:1로 AA 미달**이다(라벨이 15px bold라 large text 예외도 못 받는다). 시트가 그렇게 그려져 있어 일단 시트대로 두었다.

해소하려면 셋 중 하나가 필요하다 — **미결정**:
1. Primary 면을 `#D14B3B` 정도로 낮춘다 (대비 4.5, 시트와 눈에 띄게 다름)
2. 라벨을 18.66px bold 이상으로 키운다 (large text 기준 3.0 적용 → 여전히 2.73이라 미달, 면도 함께 조정 필요)
3. AA 미달을 브랜드 결정으로 수용하고 문서에 남긴다

## 영향 범위
- 전역 토큰이라 `app/` 내부 화면(리포트·스튜디오·매칭·라이브러리)도 자동으로 새 팔레트를 따라간다.
- 하드코딩된 옛 색(`#ff6464` 등)이 남아 있으면 어긋난다 → 후속 스윕 필요.
