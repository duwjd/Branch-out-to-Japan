# 결정 — 목 소셜 로그인을 차단한다 (2026-08-31)

> Phase 1 M15-1. 사용자 지시는 "소셜 로그인은 당분간 hide" 였으나, **숨기는 것만으로는 닫히지 않는 경로가 둘 있었다.**

## 배경 — 인증 없이 세션을 내주는 길이 둘이었다

소셜 3종(카카오·네이버·구글)은 실 OAuth 가 아니라 **목 세션**이었다(2026-07-21 스프린트 2 결정 — "버튼 클릭 = 로그인 가정"). 개발 편의로 만든 것인데 배포본(`branch-out-to-japan.vercel.app`)에 그대로 열려 있었다.

**① 라우트** — `POST /api/auth/login` 이 자격증명을 전혀 검사하지 않았다.

```
POST /api/auth/login   {"provider":"kakao"}   →   yoake_session 쿠키 발급
```

**② 레거시 쿠키 경로 (이쪽이 더 나쁘다)** — `lib/server/session.ts` 의 `resolveSessionUncached` 에 M2 이전 원시 provider 쿠키 호환 분기가 남아 있었다.

```ts
if (AUTH_PROVIDERS.includes(value as AuthProvider)) {   // value === 'kakao' 면
  const user = await store.getUserById('demo-user');     // 서명 검증 없이 통과
  return { user: …, provider: value };
}
```

**요청조차 필요 없다.** 브라우저에서 쿠키를 `yoake_session=kakao` 로 세팅하면 그걸로 끝이었다. 그리고 `demo-user` 는 레거시 브랜드 데이터의 소유자다.

## 결정

1. **`POST /api/auth/login` 은 항상 404.** 파일은 지우지 않고 남긴다 — 실 OAuth 를 붙일 때 **여기가 교체 지점**이고, 왜 막았는지가 그 자리에 있어야 한다.
2. **레거시 원시 provider 쿠키 경로를 제거한다.** 이제 서명 세션(`v1.`)만 통한다.
3. **소셜 로그인은 `SOCIAL_LOGIN_ENABLED = false` 로 끈다.** 삭제가 아니라 스위치다. env 가 아니라 코드 상수인 이유는 이 개발 머신에서 `.env*` 편집이 차단돼 있어서다.
4. 로그인 카드를 **이메일 단독**으로 바꾼다. `components/auth/SocialButtons.tsx` 는 **남겨 둔다** — 각 사 브랜드 심볼·상태 처리가 들어 있어 되살릴 때 그대로 쓴다.

`AuthProvider` 타입과 `PROVIDER_LABELS` 는 **유지한다.** 서명 세션 payload 가 `provider` 를 담고 있어 마이페이지 배지가 그것을 읽는다.

## 감수하는 것

| | |
|---|---|
| **기존 목 세션이 무효가 된다** | 원시 provider 쿠키를 들고 있던 세션은 다음 요청에서 `/login?expired=1` 로 튕긴다. **애초에 인증된 적이 없으므로 의도한 결과**지만, 쓰던 사람 입장에서는 갑자기 로그아웃된다 |
| **로그인 수단이 이메일 하나로 줄어든다** | 실 OAuth 가 붙기 전까지 소셜을 선호하는 사용자에게 진입 마찰이 는다. 다만 그 소셜은 **실제로 인증하지 않았으므로** 잃는 것은 편의뿐이다 |
| `DEMO_USER` 상수가 죽은 코드로 남는다 | 제거한 경로의 폴백이었다. 문서가 참조하고 있어 이번엔 두고, 실 OAuth 작업 때 함께 정리한다 |

## 되살리는 조건

**실 OAuth 연동이 끝났을 때.** 그때 `app/api/auth/login/route.ts` 를 OAuth 콜백 핸들러로 교체하고 `SOCIAL_LOGIN_ENABLED` 를 `true` 로 되돌린 뒤 `LoginCard` 에 `SocialButtons` 를 다시 올린다. **레거시 쿠키 경로는 되살리지 않는다.**

## 검증

배포본이 아니라 로컬(`npm run start`)에서 확인했다.

| | 결과 |
|---|---|
| `POST /api/auth/login {"provider":"kakao"}` | **404** · `set-cookie` 없음 |
| `Cookie: yoake_session=kakao` 로 `/app` | **307 → `/login?expired=1`** |
| `/login` 화면 | 소셜 버튼 0개 · 이메일 패널만 |
