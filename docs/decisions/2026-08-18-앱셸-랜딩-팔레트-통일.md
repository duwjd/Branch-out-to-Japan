# 일출 코랄 팔레트로 전면 통일 (구 스티비 coral 폐기)

- 일자: 2026-08-18 (병합 정리 2026-08-19)
- 상태: 확정
- 관련: `docs/decisions/2026-08-18-리브랜딩-yoake.md`, `app/globals.css`, `design/DESIGN.md`

## 배경

Figma에서 앱 셸 화면(사이드바 `1120:2291`, 콘텐츠 `1120:2322`, 온보딩·홈)을 **YOAKE Web** 컬렉션
토큰으로 리스타일하면서, 이 컬렉션이 코드의 `--color-lp-*`(랜딩 전용 토큰)와 값이 1:1로 같다는
사실이 드러났다. 그런데 그 토큰 블록에는 이런 주석이 달려 있었다.

> 랜딩(/) 전용 토큰 — 앱 셸(/app)에서는 쓰지 않는다.
> 앱 UI 브랜드색은 그대로 coral #ff6464다(CLAUDE.md).

즉 **Figma의 앱 화면은 랜딩 팔레트로 넘어갔는데 코드의 앱 셸은 스티비 팔레트에 남아 있었다.**
실제로 `app/app`·`components/app`의 `lp-*` 사용은 0건이었다.

## 결정

**로고·랜딩·앱이 하나의 팔레트를 쓴다.** 브랜드 원색은 로고의 일출 코랄 `#ff6f61`, 바탕 `#faf8f5`,
선 `#e9e7e3`, 잉크 `#182333`. 스티비 coral `#ff6464`·`#d93636`·`#fff8f8`은 폐기한다.

CLAUDE.md의 "로고 색을 UI 토큰으로 승격하지 않는다"는 이 결정으로 폐기됐다. 리브랜딩으로
서비스명이 YOAKE가 된 이상 로고의 일출 코랄과 UI 브랜드색을 갈라 둘 이유가 없어졌다.

## 두 브랜치가 같은 전환을 각자 했다

`main`(코랄 스윕 `e9b3230`·`508a3e2`)과 `hanna`(앱 셸 토큰)가 서로 모른 채 같은 결정에 도달했다.
`--color-*`·`--radius-*` 전량을 대조한 결과:

| | 건수 |
|---|---|
| 값까지 일치 | 34 |
| 값 상이 | 19 |
| main 에만 있음 | 10 |
| hanna 에만 있음 | 1 |

브랜드 원색·`coral-tint`·`page`·`canvas`·잉크 3단계·`lp-*` 별칭은 값까지 우연히 같았다.
**상이·단독 항목은 범위가 더 넓은 main 값을 채택한다.** 근거:

- `coral-strong` — main `#c93f2e` / hanna `#c44439` 의 **대비가 세 배경 모두에서 동일**
  (흰 4.96 · tint 4.50 · warm-white 4.68). 남은 차이는 색상 미세 조정뿐인데, main에는
  `coral-hover`·`coral-pressed`·`coral-glow`가 세트로 있어 상태 전이가 완결된다.
- **상태색** green/amber/danger 9종을 main은 저채도 랜딩 값으로 이전해 뒀다. 취향이 아니라
  대비 개선이다 — `amber-text` 가 3.67(AA 미달) → 4.78.
- **중립·선** 8종을 쿨 그레이 `rgba()` 에서 웜 hex로 불투명화. 어떤 배경에 얹히든 색이 일정해진다.

## 예외 하나 — 잉크 최하 단계

main은 `ink-faint`를 `#78818f`로 두고 placeholder·각주·비활성에 함께 쓴다. `ink-mute`(`#6e7686`)와
상대 명도 간격이 **3.7**뿐이라 4단계 잉크 위계가 사실상 3단계로 읽힌다.

그렇다고 `ink-faint`를 밝히면 안 된다. **이 토큰을 쓰는 106곳 중 약 100곳이 캡션·보조 문구**라,
`#b1b6be`로 올리면 대비가 1.92:1로 떨어져 읽을 수 없다.

그래서 역할을 쪼갰다.

- `ink-faint #78818f` — 유지. 캡션·placeholder·비활성 등 **읽어야 하는** 보조 텍스트(3.71:1).
- `ink-ghost #b1b6be` — 신설. 구분선 옆 기호, 비활성 화살표처럼 **읽을 필요가 없는** 장식 요소 전용.
  대비 1.92:1이므로 텍스트에는 쓰지 않는다.

## 구현 방식

토큰 **이름은 그대로 두고 값만 옮겼다.** 앱 유틸리티 사용이 약 1,900곳, 랜딩이 322곳이라
클래스명을 갈아엎는 대신 기존 semantic 토큰의 값을 팔레트 값으로 바꿨다. `lp-*`는 랜딩 코드
호환용 별칭(`var(--color-coral)` …)으로 남는다.

## 남은 것

- **생성물 템플릿**: `lib/studio/detail/templates.tsx`·`lib/engine/rules/slides.ts`는 고객이 실제
  채널에 올리는 산출물이라 앱 UI와 스테이크가 다르다. 별도 결정 대상.
- **Figma 역방향 반영**: 활성 내비 라벨이 `brand/coral`로 잡혀 있는데, 소형 텍스트라 코드처럼
  `coral-strong` 대응 색으로 내려야 한다. Figma `YOAKE Web` 컬렉션에는 `coral-strong`을
  `#c44439`로 만들어 뒀으므로 `#c93f2e`로 맞춰야 한다.
