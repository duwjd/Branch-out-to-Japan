# 앱 셸을 랜딩 팔레트로 통일 (구 스티비 coral 폐기)

- 일자: 2026-08-18
- 상태: 확정
- 관련: `docs/decisions/2026-08-18-리브랜딩-yoake.md`, `app/globals.css`, `design/DESIGN.md`

## 배경

Figma에서 앱 셸 화면(사이드바 `1120:2291`, 콘텐츠 `1120:2322`, 온보딩 `1209:8113`·`1209:8230`·`1209:8360`)을
**YOAKE Web** 컬렉션 토큰으로 리스타일하면서, 이 컬렉션이 코드의 `--color-lp-*`(랜딩 전용 토큰)와
값이 1:1로 같다는 사실이 드러났다.

문제는 그 토큰 블록에 달려 있던 주석이었다.

> 랜딩(/) 전용 토큰 — Figma LP 2026-08. 앱 셸(/app)에서는 쓰지 않는다.
> 앱 UI 브랜드색은 그대로 coral #ff6464다(CLAUDE.md).

즉 **Figma의 앱 화면은 랜딩 팔레트로 넘어갔는데 코드의 앱 셸은 스티비 팔레트에 남아 있었다.**
실제로 `app/app`·`components/app`의 `lp-*` 사용은 0건이었다. 구체적 차이:

| 항목 | Figma(신) | 코드(구) |
|---|---|---|
| 활성 내비 | `#fff1ee` 배경 / `#ff6f61` 라벨 | `#fff8f8` / `#d93636` |
| 앱 바탕 | `#faf8f5` | `#ffffff` |
| 카드 선 | `#e9e7e3` | `rgba(112,115,124,.14)` |
| 카드 반경 | 14 | 18 |

## 결정

**앱 셸을 랜딩 팔레트로 통일한다.** 로고·랜딩·앱이 하나의 팔레트를 쓰고, 팔레트 정본은
Figma **YOAKE Web** 컬렉션이다. 스티비 coral `#ff6464`·`#d93636`·`#fff8f8`은 폐기한다.

CLAUDE.md의 "로고 색을 UI 토큰으로 승격하지 않는다"는 이 결정으로 폐기됐다. 리브랜딩으로
서비스명이 YOAKE가 된 이상 로고의 일출 코랄과 UI 브랜드색을 갈라 둘 이유가 없어졌다.

## 구현 방식

토큰 **이름은 그대로 두고 값만 옮겼다.** 앱 유틸리티 사용이 약 1,900곳, 랜딩이 322곳이라
클래스명을 갈아엎는 대신 `--color-coral` 같은 기존 semantic 토큰의 값을 팔레트 값으로 바꿨다.
`lp-*`는 랜딩 코드 호환용 별칭(`var(--color-coral)` …)으로 남긴다.

## 파생 색 2개 — 팔레트에 없어서 새로 정의했다

**`coral-strong #c44439`.** 랜딩 팔레트에는 WCAG AA를 넘는 코랄이 하나도 없다
(`#ff6f61` 2.73:1 · `#f0594b` 3.37:1 · `#db4c3f` 4.10:1, 모두 흰 배경 기준).
그런데 `coral-strong`은 링크·소형 텍스트용으로 코드에서 129곳 쓰인다. 브랜드 코랄과 같은
hue(5°)를 유지한 채 명도만 낮춰 흰 4.96:1 · coral-tint 위 4.50:1 · warm-white 위 4.68:1을
확보했다.

**`ink-faint #b1b6be`.** 팔레트의 `text/tertiary #78818f`를 그대로 쓰면 `ink-mute #6e7686`와
거의 겹쳐 4단계 잉크 위계가 3단계로 무너진다(각주·화살표 99곳). 팔레트의 중립 hue에서
기존 `#b6b8bf`의 명도를 유지해 파생했다. `#78818f`는 `lp-faint`로 남겨 랜딩에서 계속 쓴다.

## 접근성 주의

`#ff6f61`은 소형 텍스트에 단독으로 쓸 수 없다. 링크·14px 이하 라벨·coral-tint 위 텍스트는
`coral-strong`을 쓴다. Figma 시안의 활성 내비 라벨이 `brand/coral`로 잡혀 있는데, 코드에서는
`text-coral-strong`으로 구현돼 있어 코드 쪽이 접근성 기준에 맞다 — Figma를 코드에 맞춰야 한다.

## 남은 것

- **진단 판정 상태색**: 앱 `green/amber/danger`와 랜딩 `lp-review/conditional/risk`가 아직 따로다.
  판정 UI는 색+글자+기호 3중 표기를 CVD 검증까지 마친 상태라 별도 검토 후 결정한다.
- **생성물 템플릿**: `lib/studio/detail/templates.tsx`·`lib/engine/rules/slides.ts`는 고객이 실제
  채널에 올리는 산출물이라 앱 UI와 스테이크가 다르다. 별도 결정 대상.
- **Figma 역방향 반영**: 활성 내비 라벨을 `brand/coral` → `coral-strong` 대응 색으로 내려야 한다.
