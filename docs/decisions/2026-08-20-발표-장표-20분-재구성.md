# 발표 장표 20분 재구성 — 38장 → 35장

> 2026-08-20 · 상태: **확정(반영 완료)** · 배경: 30분 기준으로 만든 본편 장표를 20분 발표에 맞춰야 함
> 대상: Figma `2조 생존자들` 파일 · `한나 work` 페이지 · 섹션 `장표 정리`(1294:47676)
> 관련: [[2026-08-14-포지셔닝-3축-vs-claimops]] · [[2026-08-18-리브랜딩-yoake]]

## 왜

발표 시간이 30분에서 20분으로 줄었다. 대본 실측 결과 **10,133자 / 340자·분 기준 29.8분**으로, 장표를 손대지 않으면 10분을 초과했다.

## 무엇을 했나

### 1. 대본 트리밍 — 10,133자 → 6,667자

200자를 넘는 대본 25건을 잘랐다. 최장은 09번 402자였다. 수치·판단·결론은 남기고 중복 설명과 부연을 걷어냈다.
예) 09_PreUT_Findings 402자 → 169자. 평균 2.63, 이탈 트리거(가상 실적 수치), 최다 지목(전후 비교), 결정 3가지는 유지.

### 2. 3쌍 병합 — 38장 → 35장

장당 평균 31초로는 전환 시간을 감당하기 어려워 논리가 이어지는 3쌍을 합쳤다.

| 병합 | 새 번호 | 새 제목 | 흡수하며 뺀 블록 |
|---|---|---|---|
| 24 ThumbGoal + 25 ThumbData | 24 | 목표 셋과, 그 기준이 된 일본 몰 데이터 | 24의 `밈 이미지 생성기가 아니다`, 25의 수집 규칙 5개·용도 제한 패널 → 푸터 한 줄로 압축 |
| 29 DetailBlocks + 30 DetailPipeline | 28 | 블록으로 분해하고, 글자는 코드가 그린다 | 29의 템플릿 6종 카드, 29의 하단 노트 → 대본으로 이동 |
| 35 PostUT + 36 NextDev | 33 | 무엇을 재고, 다음에 무엇을 고칠 것인가 | 35의 자극물 설계 컬럼, 36의 하단 노트 → 대본으로 이동 |

병합 슬라이드의 4단 카드는 2×2로 접어 높이를 확보했다. 세 장 모두 본문 높이 820 이하(694 / 775 / 686)로 넘침이 없다.

### 3. 전면 한국어화 — 82건

일본어와 장식성 영어를 모두 한국어로 바꿨다.
- 규제 용어: 薬機法 → 약기법, 景品表示法 → 경품표시법, ステマ告示 → 스텔스 마케팅 고시
- 주장 표현: 肌にうるおいを与える → 피부에 수분을 준다 (13·14·23번)
- 템플릿명: クリーン物撮り → 클린 제품컷형 등 8종
- 라벨: INPUT/DIAGNOSE/CREATE/CONNECT → 입력·진단·제작·연결, GAP → 공백, BEFORE/AFTER → 전후 비교, FREE/Report/Growth/Scale → 무료·리포트·그로스·스케일, BLOCK → 블록, PHASE → 단계

**남긴 것:** 브랜드명 `YOAKE`, 플랫폼명 `Qoo10`, 기술명 `Claude API`·`GPT Image`·`satori`·`LLM`, 파일명, 출처 URL, hex 코드. 고유명사·코드라 번역 대상이 아니라고 봤다.

**감수한 것:** 13·23번의 일본어 원문(광고 심의 대상 표현 그 자체)이 사라졌다. 심의 근거로서의 원문 대조가 필요해지면 한국어 아래 작은 보조 줄로 되살린다.

### 4. 19_Branding 재디자인

브랜드·로고 소개 장인데 같은 크기 카드 3개 + 분홍 배지 라벨 + 동일한 제목·본문 리듬의 반복이라 템플릿 티가 났다. 로고는 가운데 카드에 작게 묻혀 있었고 컬러는 hex 목록이라 스펙시트로 읽혔다.

- 왼쪽에 큰 **새벽 장면**(밤 → 새벽 → 크림 그라디언트) 위에 실제 로고를 크게 배치, 브랜드 서사 문장이 헤드라인 역할
- 오른쪽은 카드 없는 사실 컬럼(이름의 뜻·표기 규칙, 로고 3형)
- 아래는 hex 나열 대신 **실제 그라디언트 바**로 밤 → 새벽 → 확산 → 명료 표시

## 후속 — 덱 전체 디자인 통일 (같은 날)

팀원이 추가한 `08_PreUT_Personas` · `09_PreUT_Findings` · `19_Branding`이 기존 장표와 달라 보인다는 지적에서 출발했는데, 확인해 보니 세 장만의 문제가 아니었다.

### 폰트 — Noto Sans KR → Pretendard Variable

구조(패딩 120/84/64 · 헤더 113 · 타이틀 50px · 푸터 18px)는 같았고 **폰트 패밀리만 달랐다.**
문제 범위는 세 장이 아니라 **20번 이후 13장 + 발표자 노트 15개**까지였다. 앞쪽(01~19)은 Pretendard, 뒤쪽은 Noto Sans KR로 갈려 있었다.

- 총 **484개 텍스트 세그먼트**를 Pretendard Variable로 전환 (Bold 309 · Regular 103 · Medium 72), 프레임 31개
- 결과: 덱 전체 텍스트 1,465개가 단일 패밀리. 혼용 0

### 반경 — 카드 14 · 버튼 10 · 필 999

기존 장표의 반경 자체가 제각각이었다(5·6·7·10·12·16·18·20·22 혼재). **기준값이라 부를 만한 게 없어서** 가장 많이 쓰인 값을 표준으로 잡고 전수 통일했다.

- 규칙: `≥100 → 999(필)` / `최소변 ≤48 → 10(버튼)` / `그 외 → 14(카드)`
- 적용 591개 — 카드 385 · 버튼 73 · 필 133
- 주요 교정: `16→14` 77 · `12→14` 76 · `18→14` 74 · `8→10` 43 · `10→14` 39 · `20→14` 36
- **최소변 16px 미만 마이크로 요소 190개는 제외했다.** 눈썹 바·도트·진행 막대 캡에 r10을 주면 형태가 뭉개진다. 통일 대상은 카드·버튼·필로 한정한다
- 결과: 16px 이상 요소의 반경은 10 / 14 / 999 세 값만 남음

### 19_Branding — 타이틀 삭제와 재구성

**타이틀 「이름부터 일본 고객의 말로 지었다」를 삭제했다.** 두 가지 이유다.
1. 새벽 패널 안에 이미 헤드라인이 있어 한 장에 제목이 둘이었다
2. 문구가 주장하는 '일본 고객의 말'을 내용(어원·로고·컬러)이 뒷받침하지 않아 다른 장의 제목들과 결이 달랐다

대신 패널 안 헤드라인을 38 → 44px로 올려 제목 역할을 맡기고, 눈썹 라벨 `19 브랜딩`은 남겼다.

**배경 그라디언트를 덱 관례로 교체했다.** 기존에는 패널 안에서 네이비→코랄→크림으로 내려오는 불투명 7스톱이라 만드는 방식 자체가 달랐다. `35_Closing`·랜딩과 동일하게 **단색 네이비 + 하단에서 올라오는 투명→코랄 글로우**로 바꿨다(스톱 `코랄 a0 → 오렌지 a0.22 → 코랄 a0.5`, 컨스트레인트 `STRETCH/MAX`). 히어로 로고는 `Logo/semicircle`의 **`Color=onDark`** 변형으로 전환하고, 수평선은 흰색 22% · 캡션은 `on-navy-muted`로 맞췄다.

**로고 운영 블록을 본문 폭 전체로 승격했다.** 오른쪽 컬럼 안 191px 카드에 들어 있어 세로형은 슬롯(54px)에 잘리고 심볼은 너무 작았다. 로고 소개 장에서 로고가 안 보이는 상태였다.

- 전용 행으로 분리 · 카드 3개를 546px로 확대 · 슬롯 높이 104px · 클리핑 해제
- 가로형 118 → **300×76** / 세로형 52×70(잘림) → **81×108** / 심볼 54 → **96×96**
- 높이 재배분: 패널 520 → 370 · 컬러 밴드 239 → 167 · 본문 간격 26 → 20
- 결과 본문 856 / 가용 876 — 넘침 없음, 잘린 인스턴스 0

### 남은 판단

반경 통일은 **가장 많이 쓰인 값을 표준으로 채택한 것**이지 원래 디자인 의도를 확인한 것은 아니다. 특정 장에서 의도적으로 다른 반경을 쓴 곳이 있었다면 이 과정에서 함께 정리됐다.

## 후속 2 — 19_Branding 최종 정리 · 붉은 글자 통일 (같은 날)

### 로고 운영 — 목업 도입 후 철회

세로형이 슬롯에 잘리고 심볼이 작다는 지적에 먼저 **실사용 목업**을 넣었다. 가로형은 웹 헤더 클로즈업(로고 + 내비 + CTA를 오른쪽에서 잘리게), 세로형은 표지 카드, 심볼은 iOS 계열 앱 아이콘(라운드 23 + 그림자)이었다.

**그러나 걷어냈다.** 세 목업이 각기 다른 형태와 테두리를 갖는 바람에, 로고를 보여주는 자리에서 로고가 아닌 것들이 더 눈에 띄었다. "로고 소개인데 조잡하다"는 판단이 맞았다.

최종은 패널 위에 로고만 놓고 광학적 크기를 맞춘 형태다.

| | 크기 |
|---|---|
| 가로형 · 기본 | 240 × 61 |
| 세로형 · 보조 | 69 × 92 |
| 심볼 · 압축 | 76 × 76 |

**교훈:** 로고 시스템을 소개하는 자리에서는 사용처를 그리는 것보다 로고 자체를 크고 조용하게 보여주는 편이 낫다. 사용처는 라벨(웹 헤더 · 발표 자료 / 표지 · 정사각 레이아웃 / 앱 아이콘 · 작은 UI)로 충분하다.

### 패널 문구 교체

「번역을 끝내는 이름이 아니라, 일본 진출의 다음 단계를 보이게 하는 시작의 이름」(44px 2줄)을 **삭제**하고, 로고 옆에 있던 「밤이 끝나고 날이 밝기 시작하는 순간」을 32px로 로고 아래에 올렸다.

판단 근거 셋이다.
1. **중복** — 오른쪽 「이름」 단락이 같은 말("불확실했던 일본 진출의 다음 단계가 보이기 시작한다는 뜻을 이름에 담았다")을 이미 하고 있었다
2. **논지 위치가 어긋남** — 저 문장은 제품 논지인데 그건 `16_Redefinition`이 정면으로 다룬다. 브랜딩 장에서 반복하면 같은 주장이 두 번 나온다
3. **주인공이 밀림** — 44px 두 줄이 로고보다 먼저 읽혀서, 로고 소개 장인데 로고가 두 번째였다

결과적으로 패널은 **로고 + 뜻 한 줄** 두 요소만 남았다. 「브랜드 서사」 라벨과 수평선도 제거. 패널 높이 520 → 330, 본문 836 / 가용 876(여유 40).

### 이름 설명에 한자 병기

「일본어로 '새벽'을 뜻하는 요아케에서 왔다」 → **「…요아케(夜明け)에서 왔다」**.
앞선 "모두 한국어" 지시로 뺐던 것을 되돌린 것인데, 어원 설명 자리라 한자 병기가 의미 전달에 낫다는 판단이고 `CLAUDE.md`의 표기 규칙(어원 설명에서만 병기)과도 맞는다. Pretendard에 글리프가 없어 해당 3자만 **Noto Sans JP Medium**으로 범위 지정했다.

### 붉은 글자 `#C93F2E` → `#D94848`

`09_PreUT_Findings`의 붉은 라벨이 덱 색과 다르다는 지적에서 출발했는데, 같은 색이 **11개 장표 77개 텍스트**에 쓰이고 있었다. 09번만 고치면 나머지 10장이 옛 색으로 남으므로 전수 교체했다.

- 대상: 09 「결정 1~4」 · 21 「블록 0~8」 · 22 「콜①~④」 · 24 「목표 1~3」 · 25·27 템플릿 코드 `A~H` · 26·28 단계 번호 · 33 「트랙 1~4」 등 소형 강조 라벨
- **코랄 `#FF6F61`(187개)은 유지.** 눈썹 번호·구분선·불릿은 35장 전체가 코랄로 통일돼 있어 바꾸면 전 장표 헤더가 어긋난다
- 결과: 붉은 계열 텍스트는 코랄 187 + 레드 102 두 값만

**감수한 것:** `#D94848`은 `#C93F2E`보다 밝아 흰 배경 대비가 **5.4:1 → 4.2:1**로 내려간다. 17~18px 소형 라벨이라 WCAG AA(4.5:1)에 살짝 못 미친다. 발표 투사에는 문제없으나 인쇄·접근성 기준이 걸리면 해당 라벨을 Bold로 올리거나 더 어두운 값을 재검토한다.

1920 폭으로 스케일업(폰트가 함께 커짐) → 페이지네이션 제거 → 다크 카드·그림자 제거 → 눈썹·표준 푸터 부착 순으로 정리했다. 폰트 81 · 반경 69 · 색 54개를 표준값으로 교체했다.
**주의:** 미설치 폰트는 `setRangeFontName`이 막힌다. 노드 전체를 `fontName`으로 먼저 바꾼 뒤 범위 스타일을 복원해야 한다. 또 스케일 후 반경이 다시 소수점으로 틀어지므로 반경 정규화는 스케일 **뒤에** 한 번 더 돌린다.

### 33번 막대 그라디언트

과업별 만족도 8개 막대가 초록 → 코랄 → 주황 → 연코랄 → 빨강 순이라 **값의 순서와 색의 순서가 어긋났다.** 3.65가 3.75보다 연했고 3.30에서 빨강으로 튀었다. 순위 차트에 범주형 색을 쓴 것이 원인.

값 순서대로 **8단계 연속 램프**로 교체했다 — `#FF9B70`(4.60) → `#FF6F61`(중간) → `#D94848`(3.10), 덱에 있는 세 색을 앵커로 보간. T1의 초록은 제거했다(순위 차트에 범주색 하나만 섞여 있던 것이 어수선함의 원인). 우측 「끝까지 스크롤 20/20」의 초록은 달성 여부라 성격이 달라 유지.
