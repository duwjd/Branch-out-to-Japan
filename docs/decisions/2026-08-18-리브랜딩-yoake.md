# 리브랜딩 — KGLOW → YOAKE

> 2026-08-18 · 상태: **확정** · 배경: 새 로고 자산이 인계되었고, 레터마크가 `YOAKE`로 조판되어 있어 기존 서비스명 `KGLOW`와 충돌
> 관련: [[../../design/brand/logo/README.md]] · [[../../CLAUDE.md]] · [[DECISIONS]]

## 결정

1. **서비스명 = `YOAKE`** — 전부 대문자, 붙여 쓴다. 2026-07-16 확정했던 `KGLOW`를 **대체**한다(폐기).
   어원은 일본어 **夜明け**(요아케 · 동트기·새벽) — 일본 시장에서 브랜드가 처음 빛을 보는 순간.
2. **로고 = 일출 심볼 + `YOAKE` 레터마크 가로형 락업.** 수평선 3줄 위로 해가 69%만 떠오른 형태.
   구 아이덴티티(코랄 구체 + 흰 스우시 + 네이비 워드마크 + `Japan Growth Studio` 서브카피)는 **전면 폐기**.
3. **로고 전용 고정색 교체** — 해 `#FF6F61`→`#FF9B70`(좌→우) · 수평선 `#FF6F61` · 레터마크 잉크 `#182333`.
   구 네이비 `#22304F`는 은퇴. ~~**디자인 시스템 브랜드색은 변경 없음** — CTA·칩·아이콘버튼은 그대로 스티비 코랄 `#ff6464`.~~
   → **이 줄은 같은 날 오후 결정으로 폐기됐다.** 앱 셸이 랜딩 팔레트로 통일되면서 UI 브랜드색이
   로고의 일출 코랄 `#ff6f61`이 됐다. 스티비 코랄은 폐기 → [2026-08-18-앱셸-랜딩-팔레트-통일.md](2026-08-18-앱셸-랜딩-팔레트-통일.md).
4. **명칭은 코드까지 일괄 교체** — 컴포넌트(`KglowLogo`→`YoakeLogo`·`KglowMark`→`YoakeMark`), 자산 파일명(`kglow-*.svg`→`yoake-*.svg`),
   저장 키·커스텀 이벤트(`kglow:sidebar-collapsed`·`kglow:brand-switched` → `yoake:*`), 데모 계정 도메인(`demo@yoake.example`)까지 포함.
5. **과거 의사결정 기록은 고쳐 쓰지 않는다** — `docs/decisions/`의 기존 행에 남은 맥락은 이력이다. 다만 본문 표기는 일괄 치환되었으므로,
   "2026-07-16 KGLOW 확정"의 사실관계는 이 문서가 정본이다.

## 배경

새 로고 파일 2종(심볼 40×40 · 가로형 락업 103×26)이 인계됐다. 락업의 레터마크를 렌더해 확인한 결과 글자는 `KGLOW`가 아니라 **`YOAKE`** 였다.
심볼도 구체+스우시가 아니라 **수평선 위의 일출**로, 이름 `夜明け`를 직역한 형태다. 즉 자산 교체가 아니라 **아이덴티티 교체**다.

로고만 바꾸고 이름을 두면 락업에 박힌 글자(`YOAKE`)와 제품 카피(`KGLOW`)가 어긋나므로, 제품 오너 확인을 거쳐 **전면 리브랜딩**으로 진행했다.

## 이름의 전략적 적합성

| 관점 | 판정 |
|---|---|
| 일본 고객 관점 | 일본어 단어라 현지에서 의미가 즉시 읽힌다. 구 `KGLOW`는 "K뷰티 + glow"라는 **한국 발신자 시점**의 이름이었다 — 포지션("번역이 아니라 일본 고객 관점의 재설계")과 이름이 이제 일치한다 |
| 카테고리 충돌 | `Japan Growth Studio`는 여전히 **카테고리 서술어**로만 병기한다(이름 아님) |
| 표기 리스크 | 로마자 `YOAKE` 고정. 한자·가나(`夜明け`·`ヨアケ`)는 어원 설명에서만 병기 — 이름 자리에 쓰면 검색·핸들이 갈라진다 |

## 감수하는 리스크 (명시)

- **`KGLOW` 자산의 대외 노출 이력** — 발표 덱·페르소나 시뮬레이션 기록 등에 구 이름이 남아 있다. 시뮬레이션 결과 문서는 **당시 자극물이 `KGLOW`였다는 사실 자체가 데이터**이므로 표기 치환이 곧 사실 왜곡은 아니지만, 인용 시 시점을 밝힌다.
- **원본 서체 미인계** — 레터마크는 아웃라인 패스로만 받았고 원본 서체 정보가 없다. 글자를 추가·변경해야 하면 자산 제작처에서 새 아웃라인을 받아야 한다(재조판 금지 — `logo/README.md` §7).
- **저장 키 변경** — `kglow:sidebar-collapsed` → `yoake:sidebar-collapsed`. 기존 사용자의 사이드바 접힘 상태가 1회 초기화된다(UT 전이라 영향 미미).
- **최소 크기 상향** — 새 심볼은 수평선 3줄 때문에 20px 미만에서 뭉개진다(구 심볼 16px). 16~19px 자리가 있으면 `Y` 이니셜로 대체한다.
