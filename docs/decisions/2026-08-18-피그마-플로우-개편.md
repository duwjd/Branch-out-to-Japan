# 2026-08-18 — Figma 디자인 반영 · 서비스 플로우 개편

Figma `제목 없음`(fileKey `U1wp5FKg9xW7Q6h5ByYwLA`) 2026-08 시안을 코드에 반영하면서
서비스 플로우 네 가지를 함께 바꿨다. 되돌리기 어려운 결정만 남긴다.

## 1. `/app` 이하 로그인 필수 — 서비스 내부 로그인 동선 제거

**결정.** 로그인은 랜딩 헤더에서만 시작한다. `/app/*`에 비로그인으로 들어오면 `/login`으로,
쿠키가 무효면 `/login?expired=1`로 보낸다.

**버린 것.** 게스트가 `/app`을 둘러보다 제출 시점에 모달로 로그인하던 just-in-time 게이트
(`components/auth/LoginGateModal.tsx`·`useLoginGate.ts`와 6개 호출부). 제출 중 401은 이제
로그인 화면으로 보낸다 — 세션 만료 말고는 도달할 수 없는 경로다.

**남긴 것.** API의 401 분기는 그대로 둔다. 화면 가드가 한 곳뿐이라 방어선이 하나 더 필요하다.
`getSessionState()`의 3분기도 유지한다 — 착지 화면이 다르기 때문이다(만료만 배너를 띄운다).

**대가.** 딥링크가 로그인 후 원래 주소로 돌아가지 않는다. 되살리려면 `middleware.ts`로 경로를
넘겨야 하는데, 그러면 가드가 두 곳이 된다. 이번에는 받아들였다.

## 2. 계정당 브랜드 1개 — 다중 브랜드 등록·관리 제거

**결정.** 사이드바 브랜드 스위처, 브랜드 추가 모달, 브랜드 삭제, 마이페이지 브랜드 목록,
`POST/DELETE /api/brand/[id]`를 없앴다. `POST /api/brand`는 두 번째 브랜드에 409를 준다.

**남긴 것.** 온보딩(첫 브랜드 등록)과 `/app/brand` 브랜드 정보 수정(제품 관리 포함).
**DB 스키마와 `brandProfileId` 스코핑, 소유 검증 체인(`sessionOwnsBrand`)은 손대지 않았다.**
`getActiveBrand()`도 이름과 시그니처를 유지했다 — 호출부가 20곳 넘고, 해석기 한 곳만
"내 브랜드 중 최신 1건"으로 좁히면 되기 때문이다.

**대가.** 과거에 브랜드를 2개 이상 만든 계정은 나머지 브랜드에 UI로 닿을 수 없다. 데이터는
그대로 있고, 남아 있는 `yoake_brand` 쿠키가 내 목록 안에 있으면 그 브랜드를 계속 쓴다.

## 3. 마케팅 스튜디오 진입 = 메뉴 화면

**결정.** `/app/studio`를 새로 만들고 사이드바 "마케팅 스튜디오"가 여기를 가리킨다.
카드 3장(썸네일·상세페이지·SNS 피드) 중 하나를 고르면 각 퍼널로 들어간다.
두 퍼널 안에 있던 모듈 탭은 "← 마케팅 스튜디오" 링크로 바꿨다.

**SNS 피드는 만들지 않았다.** Figma에 메뉴 카드만 있고 하위 화면이 없어서, 카드는 노출하되
"준비 중"으로 두고 이동하지 않는다. 준비 중 표기의 단일 출처를 메뉴로 옮겼다.

## 4. 썸네일 해설 계약 변경 — `ExplanationJson` 확장

Figma 생성 결과 화면이 세 가지를 새로 요구했다: **제품명**(H2), **원본 한 줄 진단**,
그리고 카피 해설 카드의 **대응 한국어 원문**(기존 `krIntent`는 "의도"였다).

```
ExplanationJson: + productName, + beforeSummary
copySlots[]:     krIntent → krSource
```

콜⑥ `studioCopy` 스키마·프롬프트·검증에 반영했고, 콜⑦ `detailCopy`도 같은 슬롯 모양을 쓴다
(상세페이지 화면은 두 신규 필드를 쓰지 않아 빈 문자열로 저장한다).

**마이그레이션은 없다.** `explanation_json`은 jsonb이고, 이미 저장된 행은 읽을 때
`lib/studio/explanation.ts`의 `normalizeExplanation()`이 현재 모양으로 맞춘다
(`krIntent`를 `krSource`로 승계, 없는 필드는 빈 문자열). 생성 시점 산출물이라 되돌려 채울
수도 없다 — 읽기 정규화가 유일하게 정직한 방법이다.

**`productName`은 비어도 통과시킨다.** 이미지에서 안 읽히는 제품명을 지어내는 것보다
브랜드명으로 폴백하는 편이 낫다. 재시도는 총 1회뿐이라 화면이 대체할 수 없는 것
(`beforeSummary`·슬롯 3필드)에만 쓴다.

## 미해결

- **LP 스팟 일러스트레이션 미반영.** Figma 자산 호스트(figma.com)가 이 실행 환경의 네트워크
  정책에 막혀 내려받지 못했다. 임의로 다시 그리지 않고 비워 뒀다 — 디자이너가 SVG를 내보내
  `public/landing/`에 넣고 각 섹션에 슬롯을 채우면 된다.
- **Figma 썸네일 화면에 플랫폼 선택 UI가 없다.** 플랫폼은 템플릿 추천·결과 배지·다운로드
  파일명을 좌우하므로 없앨 수 없어, 템플릿 카드 위 칩 줄(카테고리 칩 자리)로 유지했다.
