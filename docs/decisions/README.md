# 의사결정 (ADR)

> **되돌리기 어렵거나 팀에 영향을 주는 결정**을 남긴다. 무엇을 정했는지보다 **왜 그렇게 정했고 무엇을 감수했는지**가 중요하다.
> 지식베이스 홈 = [../README.md](../README.md) · 규약 = [../CONVENTIONS.md](../CONVENTIONS.md)

## 두 층으로 되어 있다

| | 무엇 | 언제 본다 |
|---|---|---|
| **[DECISIONS.md](DECISIONS.md)** | 모든 결정을 한 행씩 담은 **표 정본** + **지금 살아 있는 미결정** | 먼저 여기를 본다. 대부분 여기서 끝난다 |
| 개별 파일 | 그 행의 상세 — 배경·대안·감수한 것 | 표의 한 행으로 부족할 때 |

**미결정이 궁금하면 [DECISIONS.md](DECISIONS.md) "미결정" 절이 정본이다.** Phase 0 종료 시점에 살아 있는 것은 다섯이다 — 수요 미검증 · 폐루프 반증 · 면책 대가물 부재 · 가격·결제 · **Phase 1 범위 미정**.

## 결정을 새로 남길 때

1. [DECISIONS.md](DECISIONS.md) 표에 한 행. 날짜 · 결정 · 배경/대안 · 상태.
2. 배경이 길면 `YYYY-MM-DD-주제.md` 로 파일을 만들고 표에서 링크한다.
3. **감수한 것을 반드시 쓴다.** 이 저장소의 ADR 은 "AA 미달을 알고 채택했다", "DB 분리는 보류했다" 처럼 대가를 함께 적는 관례를 지켜 왔다.
