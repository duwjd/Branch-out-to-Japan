# 포지셔닝 — 3축 Japan Growth Studio vs ClaimOps

> 2026-08-14 제기 · **2026-08-15 결정 완료** · 배경: 서비스명을 YOAKE로 바꾸며 20분 발표 장표를 제작하는 과정에서, 장표의 제품 서술이 기존 문서의 3축 구조와 다르다는 점이 드러남

## 결정 (2026-08-15)

**3축 Japan Growth Studio를 유지하고, ClaimOps는 내부 진단 엔진의 이름으로 격하한다.**

| 항목 | 결정 |
|---|---|
| 상위 포지셔닝 | **K-Beauty Japan Growth Studio** (한국어: K뷰티 일본 그로스 스튜디오). 영문은 `Japan Growth Studio` — `Japanese Growth Studio` 금지(일본계 스튜디오로 오해) |
| ClaimOps | 서비스 카테고리 **아님**. 주장 분류·근거 연결·위험 상태·대체 표현·변경 이유·규정 버전·승인 이력을 담당하는 **내부 진단 엔진**을 가리킬 때만 보조 사용("ClaimOps 기반 진단 엔진") |
| 현재 MVP | **① 진단 리포트 + ② 마케팅 스튜디오** — 진단 리포트만 MVP인 것처럼 쓰지 않는다 |
| ③ 운영 서비스 | **MVP 이후 확장 가설**로 재정의 — 브랜드에게 적합한 **일본 마케팅 회사·유통 채널 소개·연결**. 직접 광고 집행·유통이 아니며 입점·성과·실적을 보장하지 않는다 |
| 가치 구조 | `Diagnose. Create. Connect.` — Connect에는 항상 `MVP 이후` 라벨 |
| 핵심 차별점 | 진단 결과가 그대로 제작의 입력값이 되는 **폐루프**. "검수하는 곳은 다시 만들지 않고, 만드는 곳은 근거까지 관리하지 않는다" |

**결정 방식:** 아래 「결정을 가르는 질문」의 검증 결과로 정한 것이 **아니다.** 제품 오너가 서비스 구조를 직접 확정했고, ClaimOps 서사는 ①의 엔진 설명으로 흡수됐다. 따라서 아래 반증 조건은 폐기되지 않고 **MVP 가설의 반증 조건으로 이어진다**(발표 장표 15번).

**반영 완료:** 발표 장표 본편 20장·부록 A1~A9·발표자 노트 20개 전면 반영(2026-08-15) · `CLAUDE.md` · `design/brand/logo/README.md`.

**남은 확인:** 이 결정은 "무엇을 만들고 어떻게 말할지"를 정한 것이지, 수요를 검증한 것이 아니다. 아래 근거 상태 절은 그대로 유효하다.

## 무엇이 갈렸나

같은 고객(일본 진출 한국 인디·중소 뷰티 브랜드)을 보지만 **파는 물건이 다르다.**

- **3축 Japan Growth Studio** — 진단 리포트 · 마케팅 스튜디오 · 운영. 완성된 콘텐츠를 만들어 준다. ([[2026-07-04-상품-구조-구체화]], 확정 2026-07-04)
- **ClaimOps** — 광고 주장을 일본에서 검토 가능한 카피·근거·변경 이력으로 바꾼다. 판단과 그 기록을 판다. (2026-08-14 발표 장표)

## 비교

| | 3축 Japan Growth Studio | ClaimOps |
|---|---|---|
| 파는 것 | 완성된 콘텐츠 — 리포트 문서, 일본향 상세페이지, 썸네일, 피드 (`1 게시물 = 1 콘텐츠`) | 검토 가능한 상태 — 카피 + 판단 상태(검토가능·조건부·고위험) + 근거 매핑 + 변경 이력 |
| 푸는 병목 | 만들 손과 일본 감각이 없다 | 만들어도 통과가 안 되고, 반려 이유를 설명 못 한다 |
| 범위 | 진단 → 제작 → 운영(기업 매칭까지) 넓게 | 광고 문구 한 줄의 심의 구간만 좁고 깊게 (일반 스킨케어 보습·사용감·성분부터) |
| 통과해야 할 상대 | 일본 소비자 (사면 성공) | 일본 소비자 **이전에** 제조판매업자·수입 파트너·유통사·매체 — **승인자 역할이 새로 등장** |
| 성공 지표 | 전환·매출·리뷰 — 브랜드에 귀속, 우리 기여 증명이 어렵다 | 1차 심의 통과율 · 수정 왕복 횟수 · 소재 준비 시간 — 제품에 귀속, 측정이 쉽다 |
| 해자 | 일본 소비자 취향·유행어·감성어 데이터, 메시지 재설계 노하우 | 규제 스택 + 실제 승인·반려 결과 데이터(공개 조문이 아님) |
| 경쟁 위치 | Canva·ChatGPT·제작 대행사와 경계가 얇다 — 금지 포지션 1~5와 계속 부딪힌다 | 범용 생성툴이 흉내내기 어렵다. 대신 "법적 보증 안 함" 경계를 매번 명시해야 한다 |
| 가격 서술 | 진단 30만 → 스튜디오 월 20만 (기존 퍼널) | 셀프서비스 월 59만 / 팀 89만 / 전문가 검토 별도 (장표 19) |

## 관계를 보는 두 가지 방식

**(A) ClaimOps는 3축의 ②스튜디오 안에 들어가는 한 레이어다.**
스튜디오가 카피를 만들 때 심의 판단과 근거를 붙여 주는 기능. 3축 구조는 그대로 두고 기능이 하나 깊어진다.

**(B) ClaimOps가 서비스 정체성 자체다.**
장표 06번이 이 입장이다 — 일본 진출 성패의 6개 변수 중 "크리에이티브·심의 운영" **하나만** 우리 것이라고 명시적으로 좁혔다.
이 경우 ③운영의 기업 매칭은 서사에서 빠지고, ①리포트도 "일본 고객 관점 진단"에서 "제품 분류·승인 정보 확인" 쪽으로 성격이 바뀐다.

## 이미 지은 것과의 관계

현재 구현 상태([[../10-implementation-status]]): ① 리포트 9블록 파이프라인 + ② 스튜디오 상세페이지·썸네일.

- **(A)로 가면** — 기존 자산이 거의 그대로 얹힌다. 추가 작업은 스튜디오 안의 판단·근거 레이어.
- **(B)로 가면** — 리포트의 페르소나·USP 블록은 살아남고, 생성 기능 위에 판단·근거·이력 레이어를 새로 얹어야 한다. ③운영의 기업 매칭은 로드맵에서 내려온다.

## 결정을 가르는 질문

장표 15번의 반증 조건이 정확히 이 질문이다.

> **"고객은 판단보다 완성 이미지만 구매한다"** — 참이면 3축, 거짓이면 ClaimOps.

### 근거의 현재 상태 (중요)

기존 페르소나 20종(P01~P20)은 전부 *콘텐츠 만들 손이 없다 / 입점했는데 정체됐다 / 외주비가 부담이다* 유형이고,
**심의 반려나 규제 때문에 막혔다는 페르소나는 한 명도 없다.**

즉 지금까지 쌓은 리서치는 **3축 쪽 수요를 지지**하며, ClaimOps 수요는 아직 인터뷰로 확인된 적이 없다.
장표가 ClaimOps를 "확정 사실"이 아니라 **가설 + 8주 검증 계획**으로 배치한 것은 이 상태를 반영한 정직한 구성이다.
이 문서도 같은 이유로 **어느 쪽도 확정하지 않는다.**

## 결정 전까지의 운영 규칙

- 한 산출물 안에서 두 서술을 **섞지 않는다**. 발표 장표는 ClaimOps 서사로 일관되게 두고, 제품 문서·앱 카피는 3축 서술을 유지한다.
- 카테고리 서술어도 마찬가지 — `일본향 메시지 설계가 내장된 Japan Growth Studio`(문서) / `일본향 Beauty ClaimOps`(장표) 중 하나를 골라 쓰고 한 문서 안에서 병기하지 않는다.
- 서비스명 **YOAKE**는 이미 확정이므로 포지셔닝 결정과 무관하게 전면 적용한다.
