# specs/ — 개발 착수용 스펙 (3축 넘버 규칙)

넘버는 **작성 순서가 아니라 3축(제품 라인) 기준**이다.

> **여기 문서는 전부 [[../04-roadmap]] Phase 0 산출물**이다. 아래 "상태" 열은 Phase 0 종료 시점(2026-08-31) 기준이며, 문서별 상태·갱신일은 각 파일 상단 속성에서도 읽을 수 있다(규약 = [CONVENTIONS](../CONVENTIONS.md)).
> ⚠ **초안이 많다** — 화면 기획서 4묶음은 코드가 먼저 나간 뒤 갱신되지 않은 부분이 있다. 구현과 어긋나면 [[../10-implementation-status]] 가 사실이고, 이 문서는 의도다.
