### 0-3 계획과 달랐던 것 (정직하게)

- **실사용자 UT 를 못 했다.** 8/1~3 예정이었던 실사용자 UT 대신 합성 페르소나 UT 로 대체했다. **합성 페르소나는 구매 행동을 예측하지 않는다** — WTP 18/20·NPS −70 은 실제 전환율이 아니라 상대 비교 신호다.
- **일정이 8/9 → 8/21 로 밀렸다.** 8월 후반은 리브랜딩·디자인 시스템 전환·UT·발표 자료에 쓰였고, 8/22~31 은 계획에 없던 협업 기반 정비(0-G)에 쓰였다.
- **v6 스펙(블록 재구성)이 코드에 반영되지 않았다.** 배포본과 UT 는 개정 전 블록 0~9 기준이다([[10-implementation-status]] 헤더).
- **결제는 목업으로 남았다.** 샘플→풀 열람 경계는 정의만 있고 집행은 미구현.

## 이력 — 폐기된 컨시어지 로드맵

초기(2026-07-02~07-03)에는 **"랜딩 검증 → 작동 서비스"** 2단계 컨시어지 로드맵이 있었다. 툴을 만들지 않고 사람이 직접 리포트를 써 주는 모델이었다.
**2026-07-04 셀프서브 빌드 전환 결정으로 폐기**됐다([[decisions/DECISIONS]]). 기존 Next.js 앱 코드는 git 이력에 보존.

> ⚠ 그 로드맵도 단계를 `Phase 1`·`Phase 2` 로 불렀다. **위의 Phase 0/1 과 무관한 번호**이므로, 옛 문서에서 이 표기를 만나면 "컨시어지 로드맵"으로 읽는다. 신규 산출물에는 쓰지 않는다.

## 원칙

- 각 단계는 **검증 가능한 완료 기준**을 갖는다.
- **일본향 메시지 설계가 내장된 도구를 만든다** — 범용 자동생성·번역툴로 흐르지 않는 것이 경계선 ([[00-positioning]]).
- 산출물이 6대 금지 포지션(자동 광고영상·쇼츠변환·채널분석·예약발행·번역·종합대행)으로 흐르면 즉시 교정한다.
