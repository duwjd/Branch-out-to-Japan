## 구조 한눈에

- **대상:** **배포본 https://branch-out-to-japan.vercel.app** (Vercel Hobby + Supabase Free). 로컬 dev 서버는 쓰지 않는다
- **참가자:** 페르소나 20인 = 계정 20개 (`P{nn}` ↔ `test{nn}@example.com` / 공통 비밀번호). 매핑은 `.ut/accounts.json`(git 제외)
- **과업:** **T0 랜딩페이지(비로그인 · 매력도·흥미도)** → T1 로그인 → T2 브랜드 등록 → T3 진단 리포트 → T4 썸네일 → T5 상세페이지 → T6 운영 3화면 → T7 종합
- **생성:** 전원 3종 각 1회 = **60건** (리포트 20 · 썸네일 20 · 상세페이지 20). LLM·이미지 모두 실모드
- **제품컷:** 무지 용기 6종 준비 완료 ([fixtures/products/](fixtures/products/)) — 카테고리별로 20인에게 배정
- **이미지 비용:** 단가 1차 실측 완료 — `generate` 1024×1536 **$0.0420** · `edit` 1024×1024 **$0.0652**. 앞으로 100~140콜 **≈ $6~8** (계획서 §10)
- **방식:** Playwright 드라이버가 조작·캡처 → 페르소나(`Read` 전용)가 화면 PNG를 보고 반응 → 분석가가 집계

**런타임 산출물은 `.ut/`에 쌓이며 git에 커밋하지 않는다.**
