## 문서를 새로 만들 때

1. 어느 **영역**인지 정하고 그 폴더에 만든다.
2. [문서 규약](CONVENTIONS.md) §2 의 프론트매터를 채운다. 확정 전이면 `status: 초안`.
3. **해당 영역 인덱스에 한 줄 등재한다.** 등재되지 않으면 `npm run docs:check` 가 고아 문서로 잡는다.
4. 되돌리기 어려운 결정이면 [DECISIONS](decisions/DECISIONS.md) 에 한 행 남긴다.

```bash
npm run docs:check   # 속성·링크·고아 문서 검사
```
