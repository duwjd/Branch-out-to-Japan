### U3·U4 에 넣을 값

```bash
# 지금 — Gmail 경로 (임의 주소 발송 가능 · 500통/일)
MAIL_MODE=gmail
GMAIL_USER=본인@gmail.com
GMAIL_APP_PASSWORD=xxxxxxxxxxxxxxxx      # 앱 비밀번호 16자리, 공백 빼고
MAIL_FROM=YOAKE <본인@gmail.com>

# 도메인이 준비되면 — 이 세 줄만 교체(코드 변경 없음)
# MAIL_MODE=resend
# RESEND_API_KEY=re_xxxxxxxxxxxx
# MAIL_FROM=YOAKE <noreply@구입한도메인>
```

> ⚠️ **`AUTH_MAIL_MODE=devlink` 를 지우지 않으면**(U5) 실메일을 붙여도 운영에서 인증 링크가 화면에 그대로 노출된다([[../11-deploy-spec]] §4).
