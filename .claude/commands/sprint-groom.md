## 할 일

위 출력으로 **중복부터 확인하고**, 대상 마일스톤을 착수 가능한 이슈로 쪼갠다.
이슈를 만들지 않는다 — **초안과 실행 명령을 제시하고 멈춘다.**

### 1. 먼저 읽는다

- `docs/sprints/` 의 현재 스프린트 문서 — §목표·§작업 보드·§리스크. **무엇이 이미 잡혀 있는지**
- `docs/04-roadmap.md` — 이 마일스톤이 어느 Phase 목표에 매달려 있는지
- `docs/09-dev-spec.md` §4~ — 기존 마일스톤(M0~M12)이 태스크·DoD를 **어떻게 썼는지**. 그 형식을 따른다
- 코드가 필요하면 관련 모듈을 Grep 으로 짚는다. 추측으로 태스크를 쓰지 않는다

### 2. 판단한다

**이미 이슈가 있으면 새로 만들지 않는다.** 위 보드에 그 마일스톤 이슈가 있으면
"이미 N건 있다"고 말하고, 빠진 것이 있을 때만 **추가분**을 제안한다.

### 3. 쪼갠다 — 3~7건

- **하루 안에 끝나는 크기.** 이틀 넘어 보이면 더 쪼갠다. 반나절짜리 둘은 합친다
- **기획 이슈를 맨 앞에 둔다.** 이 저장소는 M13·M14·M15 모두 `기획` 이슈가 구현을 선행한다.
  기획 없이 구현부터 하면 스펙과 코드가 갈라진다
- **세로로 쪼갠다** — "API"·"UI" 로 나누지 말고 "사용자가 X 를 할 수 있다" 로 나눈다.
  단, 계기·측정처럼 **먼저 붙여야 데이터가 쌓이는 것**은 예외로 앞에 둔다
- 각 이슈에 **수용 기준을 체크박스로** 3~5개. GitHub 이 진행률을 세어준다
- 수용 기준은 **관찰 가능해야 한다.** "안정적으로 동작한다" 는 기준이 아니다.
  "예산 초과가 `failed` 가 아니라 강등으로 끝난다" 는 기준이다
- 선후관계가 있으면 본문 첫 줄에 `의존: #NN` 한 줄. 없으면 쓰지 않는다

### 4. 제시한다

**(가) 분해 표**

| # | 제목 | 왜 이 단위인가 | 선행 |
|---|---|---|---|

**(나) 이슈별 본문 초안** — 배경 2~3줄 + 수용 기준 체크박스

**(다) 실행 명령** — 사람이 그대로 붙여 넣을 수 있게

```bash
gh issue create --title "M16-1 ..." --label "M16" --body-file - <<'EOF'
...
EOF
```

새 마일스톤이라 라벨이 없으면 `gh label create` 도 앞에 붙인다.

**(라) 스프린트 문서에 넣을 표 행** — 이슈를 만든 뒤 §작업 보드에 이어야 한다.
이슈 번호는 생성 후에 정해지므로 `[#NN](...)` 자리를 비워 표시한다.

```markdown
| 16-1 ... | ⬜ | | [#NN](https://github.com/duwjd/Branch-out-to-Japan/issues/NN) |
```

## 하지 말 것

- **`gh issue create` 를 직접 실행하지 않는다.** 외부에 남는 쓰기이고, 분해는 사람이 한 번
  보고 나서 확정할 일이다. 명령까지만 제시하고 멈춘다
- **라벨을 새로 발명하지 않는다.** 마일스톤(`M13`…)·`기획`·`사용자작업`·`blocked`·`진행` 이 전부다.
  `pt:3` 같은 포인트 라벨은 이 저장소에서 쓰지 않기로 했다
- **8건을 넘기지 않는다.** 넘으면 마일스톤이 너무 크다는 신호다. 그렇게 말한다
- 스프린트 문서를 여기서 고치지 않는다. 행 초안만 제시한다
- `docs/00-positioning.md` 의 "절대 피해야 할 6개 포지션" 으로 흐르는 태스크는 그 자리에서 지적한다

## 왜 에이전트에 위임하지 않나

`/spec` 은 `pm-planner` 로 넘긴다. 이 명령은 그러지 않는다 — 분해에는 **지금 어떤 이슈가
열려 있고 문서 어디까지 적혀 있는지**가 필요한데, 그건 세션 시작 훅이 메인 세션에 이미
넣어 준 정보다. 격리 컨텍스트로 넘기면 같은 사실을 다시 조회해야 하고, 결과를 받아
`gh` 명령으로 옮기는 왕복이 한 번 더 생긴다.

마일스톤 자체가 아직 흐릿해서 **PRD 부터 필요하면** 그때는 `/spec` 을 먼저 쓴다.
