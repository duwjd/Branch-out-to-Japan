# copy/ — 카피 산출물

`jp-localizer` 에이전트(`/localize`)의 산출물을 보관한다.

규칙:
- 원안(한국어): `<이름>-kr.md`
- 재설계(일본 고객 관점 / 일본어): `<이름>-jp.md`
- 각 파일에 **선택 이유**를 함께 기록한다(번역이 아니라 재설계임을 드러내기 위해).

예: `landing-hero-kr.md`, `landing-hero-jp.md`
