# YOAKE 로고 — 자산 정본 & 사용 규칙

> **확정 2026-08-18.** 서비스명은 **YOAKE**, 로고는 이 폴더의 SVG가 정본이다.
> 이전 아이덴티티(`KGLOW` — 코랄 구체 + 네이비 워드마크 + `Japan Growth Studio` 서브카피)는 **전면 폐기**한다.
> 배경은 [../../../docs/decisions/2026-08-18-리브랜딩-yoake.md](../../../docs/decisions/2026-08-18-리브랜딩-yoake.md).
> 브랜드 전략·보이스·비주얼 서사는 [../index.html](../index.html), 디자인 시스템은 [../../design-system.md](../../design-system.md).

## 1. 네이밍

- 고객 대면 이름은 **YOAKE** 하나로 통일한다. 전부 대문자, 붙여 쓴다.
- 어원은 일본어 **夜明け(요아케 · 동트기·새벽)** — 일본 시장에서 브랜드가 처음 빛을 보는 순간. 심볼의 일출은 이 뜻을 그대로 그린 것이다.
- **쓰지 않는 표기:** `Yoake` · `YO-AKE` · `Y.O.A.K.E` · `yoake`(도메인·핸들·파일명 제외).
- 일본어 표기도 로마자 `YOAKE` 그대로 둔다. **한자·가나 표기(`夜明け` · `ヨアケ`)를 이름 자리에 쓰지 않는다** — 어원 설명 문맥에서만 병기한다.
- 상위 포지셔닝은 **K-Beauty Japan Growth Studio**(한국어: K뷰티 일본 그로스 스튜디오) — 확정 2026-08-15 → [2026-08-14-포지셔닝-3축-vs-claimops](../../../docs/decisions/2026-08-14-포지셔닝-3축-vs-claimops.md).
  - 워드마크 옆에 서술어를 붙일 때: "YOAKE — K-Beauty Japan Growth Studio". `Japan Growth Studio`는 **이름이 아니라 카테고리 서술어**이므로 단독으로 서비스명처럼 쓰지 않는다.
  - 영문은 반드시 `Japan Growth Studio`. **`Japanese Growth Studio`는 쓰지 않는다**(일본계 스튜디오로 오해된다).
  - `ClaimOps`는 로고·서비스명 옆에 붙이지 않는다. 내부 진단 엔진을 가리킬 때만 본문에서 보조적으로 쓴다.

| 파일 | 구성 | 언제 |

| [yoake-logo.svg](yoake-logo.svg) | 일출 심볼 + 잉크 레터마크 (가로형 103×26) | **기본값.** 헤더·푸터·문서 표지·발표 자료 |

| [yoake-wordmark.svg](yoake-wordmark.svg) | `YOAKE` 레터마크 단독 | 심볼을 따로 크게 쓰는 표지·굿즈 등 연출 자리 |
| [yoake-logo-mono.svg](yoake-logo-mono.svg) | 잉크 1도 (해도 단색으로 채움) | 1도 인쇄·각인·팩스 |
| [yoake-logo-mono-onDark.svg](yoake-logo-mono-onDark.svg) | 흰색 1도 | 어두운 배경 1도 |

코드에서는 SVG를 직접 import하지 말고 **[components/brand/Logo.tsx](../../../components/brand/Logo.tsx)** 의 `YoakeLogo` · `YoakeMark`를 쓴다.

```tsx
import { YoakeLogo, YoakeMark } from '@/components/brand/Logo';

<YoakeLogo height={22} />                  {/* 기본 가로형 */}
<YoakeLogo height={22} tone="onDark" />    {/* 어두운 배경 */}
<YoakeMark width={26} height={26} />       {/* 심볼 단독 */}
```

한 화면에 로고가 둘 이상이면 `uid`로 SVG 내부 id 접두사를 갈라 준다(`<YoakeLogo uid="shell-logo" />`) — 안 그러면 그라디언트·클립 id가 충돌한다.

파비콘은 [app/icon.svg](../../../app/icon.svg) — `yoake-mark.svg`의 사본이며 Next.js App Router가 자동으로 잡는다. 마크를 고치면 이 파일도 함께 갱신한다.

## 3. 색 — **로고 전용 고정색**

> ⚠ 아래 값은 **로고에만** 쓴다. 디자인 시스템의 브랜드색은 여전히 스티비 코랄 `#ff6464`이고,
> CTA·칩·아이콘버튼은 그대로 `#ff6464`를 쓴다 (`design/design-system.md`). 로고 색을 UI 토큰으로 승격하지 않는다.

| 역할 | 값 |
|---|---|
| 해 (가로 그라디언트, 좌→우) | `#FF6F61` → `#FF9B70` |
| 수평선 3줄 | `#FF6F61` |
| 레터마크 잉크 | `#182333` |

단색이 필요하면 잉크 `#182333` 또는 흰색만 쓴다. 코랄 1도 로고는 만들지 않는다.

## 4. 지오메트리 (자산 수정 시 기준값)

두 자산은 **같은 도형을 비율만 달리** 쓴다. 가로형은 마크의 `20/26` 축소판이다.

| 항목 | 마크 40×40 | 가로형 103×26 |
|---|---|---|
| 해 원 | `cx 20 · cy 20 · r 13` | `cx 10 · cy 13 · r 10` |
| 해 노출 높이 | `18` (지름의 **69%**) | `13.846` (지름의 **69%**) |
| 수평선 폭 | `26` · `21.84` · `17.68` | `20` · `16.8` · `13.6` |
| 수평선 굵기 | `1.175` · `1.196` · `1.196` (`rx` = 굵기÷2) | `0.904` · `0.92` · `0.92` |
| 심볼↔레터마크 간격 | — | `10.32` (해 지름의 **0.52배**) |

해는 원을 클립해 **위쪽 69%만** 남긴 형태다 — 반원(50%)이 아니다. 이 비율이 무너지면 일출로 읽히지 않는다.

## 5. 여백 · 최소 크기

- **보호 여백:** 해 지름의 **0.25배** 이상을 로고 사방에 비운다. 이 안에는 텍스트·괘선·이미지 가장자리가 들어오지 않는다.
- **최소 크기:** 가로형 **높이 20px**(인쇄 7mm) / 심볼 단독 **20px**(인쇄 7mm).
  20px 미만에서는 수평선 3줄이 한 덩어리로 뭉개진다. 더 작은 자리가 필요하면 로고를 줄이지 말고 잉크 `#182333` 바탕의 `Y` 이니셜을 쓴다.

## 6. 금지

- 심볼과 레터마크의 **비율·간격 변경**, 재배치 (세로형이 필요하면 이 문서를 갱신하고 자산을 추가한다 — 임의 조립 금지)
- **장평 왜곡** — 높이만 지정하고 폭은 비율에 맡긴다
- **다른 서체로 레터마크 재조판** (자산의 아웃라인이 정본)
- 레터마크를 **코랄로** 칠하기 / 해를 **잉크로** 칠하기 (모노 자산 제외)
- 해의 **노출 비율(69%) 변경**, 수평선 줄 수·수축률 변경, 그림자·베벨·광택 추가
- 해를 **원 전체로** 되돌리기 — 수평선 위로 떠오르는 형태가 아이덴티티다
- 대비가 부족한 배경(코랄 틴트·사진의 밝은 부분) 위에 잉크 레터마크 얹기 → `onDark` 또는 흰 배경 박스를 쓴다

## 7. 자산 재생성

레터마크는 **글리프를 패스로 아웃라인**한 것이라 폰트 설치·번들이 필요 없다.
원본 서체는 자산 인계 시점에 함께 전달되지 않았으므로 **다른 서체로 재조판하지 않는다** — 글자를 추가·변경해야 하면 원본 파일을 만든 쪽에서 새 아웃라인을 받는다.

곡선·간격을 바꿔야 하면 **§4의 기준값**을 갱신하고 `components/brand/Logo.tsx`와 이 폴더의 SVG를 **함께** 고친다. 둘이 어긋나면 SVG가 정본이다.
